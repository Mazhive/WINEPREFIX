Als VKD3D-Proton niet goed werkt, of als Vulkan je videokaart niet herkent als DX12-capable, denkt het spel: "Mijn videokaart ondersteunt geen D3D12 onder deze omgeving" en krijg je precies zo'n melding.

De fallback naar DX11 die in `launcher-configuration.json` staat, kan dus **nooit** werken omdat het DX11-binary gewoon ontbreekt in deze versie.

## Check of Vulkan werkt

Laat eerst zien of Vulkan jouw GPU ziet:

```bash
vulkaninfo --summary 2>&1 | head -25
```

En ook:

```bash
lspci | grep -A1 -i vga 2>&1
```

## Hoe op te lossen

### Optie 1: Gebruik Proton-GE via Lutris (meest betrouwbaar)

De nieuwe REDlauncher crasht onder bare Wine, en DX12 werkt het stabielst met **Proton-GE** (die heeft VKD3D-Proton mee ingebakken en goede fixes).

1. Installeer Lutris
2. Voeg je GOG-installatie toe (of maak een custom wine-prefix met Proton-GE)
3. Zorg dat Vulkan werkt (mesa/vulkan-radeon of nvidia)

### Optie 2: Probeer direct met VKD3D-Proton in je huidige prefix

Als je tóch met dit prefix wil proberen, kun je `vkd3d-proton` gebruiken. Maar Wine 11 alleen is niet genoeg — je hebt de vkd3d-dll's nodig.

Een simpele test:

```bash
cd /home/peter/GAME/TheWitcher3WildHuntGOTY
VKD3D_DEBUG=none WINEPREFIX=/home/peter/GAMEPREFIXES/witcher3 /opt/wine-stable/bin/wine bin/x64_dx12/witcher3.exe
```

Kijk of je dezelfde melding krijgt. Als ja, dan herkent VKD3D je GPU niet als DX12-compatible.

## Belangrijk

- **Je kunt niet terug naar DX11** met deze installatie. Die binary ontbreekt. Als je per se DX11 wil, zou je de pre-Next-Gen versie nodig hebben.
- **REDlauncher werkt niet** onder bare Wine — dat is een bekend probleem. Dus direct `witcher3.exe` starten is juist de juiste manier.
- **Vulkan is verplicht** voor DX12 op Wine via VKD3D-Proton. Zonder werkende Vulkan zie je deze "niet compatible zonder D3D12"-melding.

Stuur gerust de output van `vulkaninfo --summary` en `lspci | grep -A1 -i vga`. Dan kijk ik direct mee welke fix het meest kansrijk is voor jouw kaart.

## One-liner

Kopieer en voer dit uit in je terminal:

```bash
PROTON="/home/peter/.steam/debian-installation/compatibilitytools.d/GE-Proton11-7/proton" && export STEAM_COMPAT_CLIENT_INSTALL_PATH="/home/peter/.steam/debian-installation" && export STEAM_COMPAT_DATA_PATH="/home/peter/GAMEPREFIXES/witcher3-ge11" && mkdir -p "$STEAM_COMPAT_DATA_PATH" && "$PROTON" run "/mnt/VG_00/PUBLIC-LIBRARY/PRE-INSTALLED-GAMES/WINDOWSGAMES/TheWitcher3WildHuntGOTY/bin/x64_dx12/witcher3.exe"
```

## Uitleg

- **GE-Proton11-7**: heeft VKD3D-Proton mee. Met bare Wine crasht de REDlauncher, met GE-Proton run je de `witcher3.exe` direct (geen launcher nodig) en is DX12 ondersteuning veel beter.
- **STEAM_COMPAT_DATA_PATH**: maakt een aparte Proton-prefix (`/home/peter/GAMEPREFIXES/witcher3-ge11/`). Zo raakt dit je bestaande Wine-prefixes niet.
- **SDL3 library "Failed loading"**: die warning is meestal onschuldig met Proton-GE.
